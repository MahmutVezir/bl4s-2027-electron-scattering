# Week 2 simulation data

This directory is reserved for small, reviewable data documentation and metadata. The raw production dataset is not committed here yet.

The canonical raw records are expected to be generated and preserved in the dated Google Drive folder created by the recovery notebook. The package includes per-condition hits, primary-electron track steps, target-boundary records, event-level target-boundary analysis, ROOT export and manifests.

Do not copy a new run over an older run. Each production must retain its own directory, source commit, seed metadata and SHA-256 inventory. The validated archive should be published as an immutable GitHub Release asset and referenced here only after its hash has been checked.
